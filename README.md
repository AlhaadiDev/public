# Public

Pages for sharing outside the private app repository.

| Path | Page |
|---|---|
| `index.html` | List of shared pages |
| `geoplantation/plan/` | Lite, Premium, and Enterprise proposal |

Add the next share as a new folder, for example `geoplantation/standup/index.html`, and link it from `index.html`.

When this folder is a public GitHub repository named `public`, GitHub Pages from the repository root serves:

- `/` for the list
- `/geoplantation/plan/` for the plan
